# macOS 首包开发计划

基线为 `v0.21.0-beta`，开发分支为 `codex/macos`。面向 Apple Silicon，最低目标 macOS 13，GitHub Actions 使用 arm64 macOS 15 构建。继续使用现有桌面浏览与编辑界面。

1. 生成 Flutter macOS 目标，核对窗口、目录选择、键盘和本地数据路径。接入 ARM64 构建、应用图标和应用包校验。
2. 用 ImageIO 和 Core Graphics 实现 HEIC／HEIF 解码、方向处理和 Display P3 到 sRGB 的转换。复用桌面 JPG／PNG 导出、EXIF 写回、ICC 嵌入和断点续导。通过样片验证尺寸、颜色和元数据，保留大图尺寸限制与错误提示。
3. 用 WKWebView 实现高德地图选点、连接检测和按 GPS 查询地点。复用高德页面、坐标转换、凭据设置以及现有照片信息编辑。
4. 对照 Windows 现有功能跑一轮，包含预设管理与 .lmp／二维码、图层与组件编辑、文件监听、键盘手势、批量导出和中断恢复。尽量将可自动验证的项目留在 CI。
5. 交给测试者的首包涵盖上述功能。只要求一轮实际使用：打开样片目录，套用预设并选地点，批量导出，再核对画面和成片信息。Apple Developer ID 签名、公证和真机结果分别记录，作为对外发包的独立检查。
