## 代码边界

- `lib/export/photo_export.dart` 接现有样式渲染与编码。Windows 工作台在解码后调用，仍由自身协调批次、重名、取消、进度和续导。旧样式分支保留原编码路径。
- `lib/export/android_photo_io.dart` 与 Kotlin `AndroidP1Bridge.kt` 负责系统选择器、原文件缓存、Android 系统解码和 MediaStore 发布。平台端只处理取得原始字节和写出成片。安卓命名使用与 Windows 相同的默认模板，存储系统负责同名文件的实际落盘。
- `lib/editor/style_render.dart` 在编码前对照请求的成片尺寸与渲染结果。Android 适配层也检查系统解码尺寸和 Flutter 收到的图像尺寸。当前实验页仍按原尺寸解码，超大源图遇到设备限制时，小尺寸导出也可能受源图限制。
- `lib/editor/style_document.dart` 在文档、组件和分组层往返保留 `extensions` 对象。它只传递可选数据，不参与绘制。缺少支持的必需功能继续由现有 `.lmp` 校验拒绝。格式版本维持 1，旧版本仍使用自身的读写能力。
- `lib/settings/android_map_preview.dart` 复用已有本机页面服务和 `AppSettings` 格式，Android 通过本机应用目录保存设置。Windows 地图继续使用原有 WebView 实现。

## 已验证

- Windows 构建成功，隔离数据启动、正常退出并写入 `workspace.json`。针对导出、重名、取消、真实续导、构图、预设库的 15 项回归通过。使用 `LUMACRAFT_DATA_DIR` 设到名称含 `export-ui-check` 的新目录。
- Android 12 模拟器从系统选图器打开带 EXIF 的 HEIC，保存 JPG 和 PNG。MediaStore 两条记录都显示 `is_pending=0`，命名使用 `01-exif_LumaCraft`。
- Windows 生成预设 → Android 导入并用于导出 → Android 保存 → Windows 使用正式 `.lmp` 读取逻辑读回。另存前后整份 JSON 一致，保留横竖布局、图片标识和扩展字段。Android 实际拒绝了带未知必需功能的样本。
- 两端用同一份预设、同一张 HEIC 导出的 PNG 均为 1684 × 1428，回读均有 iCCP 和原拍摄时间。图片解码与字体栅格化可能因平台而异，本次比较覆盖构图尺寸、预设数据和输出元数据。
- 模拟器上的 48 MP 输入请求原尺寸时，目标成片为 8420 × 7140，渲染器返回 8192 × 6946。测试确认拦截后相册无新增记录。同一张图显式指定短边 1200 像素，成功保存 1415 × 1200 的 PNG。
- Android WebView 本机页面成功回传坐标 `116.397428,39.909230`。用户随后确认 P2 高德在线地图验证通过。
- 两份 Android APK 均通过包名、ABI、签名与 APK 16 KiB 对齐检查。用户随后确认 P2 ARM64 真机复测全部通过，覆盖本轮列出的 61 MP 原尺寸导出与 Display P3 HEIC。

## 命令与证据

- Windows 构建使用 `flutter --no-version-check build windows --release --no-pub`。日志为 `app/build/android-p2-windows-build.log` 和 `app/build/android-p2-windows-smoke.log`。
- Windows 回归使用 `flutter --no-version-check test --no-pub -j 1 --reporter expanded`，目标为 `test/export_pipeline_test.dart`、`test/export_workspace_flow_test.dart`、`test/export_batch_resume_test.dart`、`test/layout_adaptation_test.dart`、`test/p2_preset_roundtrip_test.dart`、`test/preset_library_test.dart`。日志为 `app/build/android-p2-windows-regression.log`。
- Android 构建沿用 P1 的 `:app:assembleDebug` 命令，把属性改为 `-PlumacraftP2=true`，并分别使用 `-Ptarget-platform=android-x64` 和 `-Ptarget-platform=android-arm64`。入口仍为 `lib/android_p1.dart`。构建日志为 `app/build/android-p2-x86_64-build.log` 与 `app/build/android-p2-arm64-v8a-build.log`。
- Android 实测记录在 `app/build/android-p2-android-verification.log`。回读预设和对照 PNG 位于 `app/build/android-p2-fixtures`，Windows 重新读取 Android 预设的测试输出见 `app/build/android-p2-android-preset-readback.log`。
