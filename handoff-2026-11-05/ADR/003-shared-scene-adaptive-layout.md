# ADR-003 · 预览/导出共用场景与横竖稀疏覆盖

状态：按当前代码及保留记录重建，2026-11-05。历史缺少决策证据的部分明确标注，不臆造。

## 背景

预设同时适配横、竖、方照片，复制两套文档会使共同文字/素材内容漂移。

## 决策

StyleDocument通用内容，加横/竖布局差异覆盖；方图使用通用。StyleScene统一几何与绘制。锚点只用于适配，不限制拖动范围；换锚点换算X/Y尽量保持位置。

## 被否决/未采用的备选与证据边界

独立复制全部横竖文档没有作为最终实现；当前共享结构不采用那种分叉。用户已否决跨区域拖动受锚点限制的行为。

## 代价与影响

嵌套覆盖、组/子组件选择、换区域坐标是高风险；应保持forRatio解析和渲染同源。

## 影响文件/核实入口

app/lib/editor/style_document.dart；style_render.dart；editor_controller.dart；test/layout_adaptation_test.dart。
