# ADR-011 · 无Git时以文件快照交接

状态：按当前代码及保留记录重建，2026-11-05。历史缺少决策证据的部分明确标注，不臆造。

## 背景

用户暂停开发并要求无歧义、可验证、与现状绑定的材料；当前没有项目Git。

## 决策

不擅自初始化Git；保存目录、命令完整输出、前后关键哈希、全工程普通文件SHA256清单和逐文件校验副本。

## 被否决/未采用的备选与证据边界

不能把版本号、SDK的commit或历史日志冒充本项目HEAD；不能把无索引的文件统称为已确认未跟踪。

## 代价与影响

只能绑定当前状态，不能重建历史提交；外部原照片/系统依赖不随工程目录自动备份，保留链接定义并映射备份内目标。

## 影响文件/核实入口

handoff-2026-11-05/evidence；tools/inventory.py、verify_snapshot.py、backup_snapshot.py；独立BACKUP_REPORT。
