# 工作台 UI 修订记录

日期为 2026-11-03。本版原型待用户确认。

## 用户明确提出的要求
- 底部照片栏可以横向铺满，两侧栏相应缩短；提供侧栏与底栏层叠关系的选项，并允许自定义组件大小。
- 顶栏、侧栏与底栏通过阴影表达层级，减少面板之间的框线。
- 强调色由绿色改为偏金的暖橙色。

## 本版实现
默认采用底栏横向铺满。顶栏圆角双图标开关直接切换底栏横向铺满或侧栏纵向铺满。顶栏固定 54 px，左右侧栏与底栏通过交界处拖动调整；浏览器保存布局。
移除了红框中的参考入口和示例说明，以及顶栏的 UI 探索标记。深色强调色暂定为 #DFA653，浅色强调色为 #9B5E14，具体观感待用户确认。

## 2026-11-04 组边界落点、照片吸附、图层图标和快捷键
用户确认后按鼠标横向缩进区分组末尾的“组内/组外”；长插入线表示同级/组外，缩进短线表示组内，并显示两枚专用线性图标和仅两个字的提示。嵌套组按对应层级解析，折叠或空组支持底部入组。底部入组对应绘制数组首位，避免落点显示在底部、实际插入顶部。
图层面板所有图标以统一 24 px 网格重绘，圆角 1.65 px 线条、柔和中性轮廓和暖金细节，覆盖组件类型、文件夹分组、展开收起、可见性、锁定、六点拖动手柄、添加、分组/解组及上下移。没有新增栅格素材。
照片区域的矩形（左/上边框偏移和照片实际宽高）作为独立对齐参考，支持边缘和水平/垂直中心；辅助线提示标明照片目标，沿用 Alt 临时关闭。实际浏览器拖动后文字左边缘为 323.2415466 px，照片左边缘为 323.2415865 px，误差小于 0.001 px，两次撤销恢复原布局。
组内任意组件都可双击单独选择：动态照片字段只打开组件属性；固定文字仍进入原位编辑；锁定组件可选择但不可编辑。为避免小字号/空格造成双击落空，SVG 文本组件启用 bounding-box 命中范围。验证拍摄参数、相机型号均可选择且不进入文本输入框，自由文字仍可编辑并 Esc 取消。
用户补充快捷键以 Adobe 惯例为准。组件复制改 Ctrl+J，Ctrl+D 改为按当前操作区域取消组件或照片选择，Ctrl+A 同样分区处理，主画布主动获得焦点以防旧照片焦点误清空；组件区支持 Ctrl+Alt+A。重做统一 Ctrl+Shift+Z，移除 Ctrl+Y。缩略图区域左右键切图、Shift 扩选；照片区域不借用删除键去删除组件，也不删除照片文件。已实现快捷键清单：
