# LumaCraft 0.15.5 · 自动关联后也会告诉你（制作版）

2026-11-06，版本 0.15.5+48。沿用 0.15.4 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次新增

- **照片移动或改名后，软件自动认出来时，底栏会出现一个「已自动关联 N 张」按钮。**
  样式是中性底色加对勾，和需要你处理的「重新关联 N 张」（强调色）区分开，不打扰。
  点开后会列出每一对「原来的文件名 → 现在的文件名」，说明套用的预设和补填的信息都已跟着照片接回，不需要再操作。点「知道了」后这条提示消失。
- 如果底栏空间不足，会先显示需要你处理的那一个。

## 本次修正（上一版）

- 改名后已自动接回却还提示「重新关联」的问题已修好。
- 关联面板点面板以外区域即关闭，和其他面板一致。

## 沿用功能

- 记住窗口位置和大小，关闭时记下，下次打开回到原处；拔掉外接显示器会退回主屏。
- 浏览和编辑两个模式的底栏都有「重新关联照片」入口。
- 关联面板「选择其他文件…」按钮常驻，随时能手动挑照片；改名也能接。
- 照片改名或对调名字后，预设和补填的信息跟着照片内容走，不跟文件名。
- 多张一起手动选时，先按拍摄时间自动配对待确认，左栏只留还需手动配的。
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致。
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸。
- 导出中软件卡住或自己退出，下次打开说明原因；自己关窗口则不提示。
- 没装 HEIC 解码时，提示下有两个按钮直接打开微软商店。
- 手机常见 HDR 用其中的普通画面；整张按高亮度编码的 HDR 暂不支持，会说明原因。
