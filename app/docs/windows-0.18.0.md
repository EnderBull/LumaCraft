# LumaCraft 0.18.0 · 设置面板与高德地点（制作版）

2026-11-07，版本 0.18.0+58。沿用 0.17.4 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次新增：设置面板

顶栏原来的明暗切换按钮换成了齿轮，点开是设置面板，分三页。

### 通用

- **深色模式**：开关，从这里切换明暗
- **打开预设文件夹**：直接打开存放你自己预设的位置
- **重新加载缩略图**：释放内存里的缩略图缓存，不会删除照片或预设
- **清理使用记录**：删除预设、照片记录、布局和导出设置。会先列出具体文件请你确认，内置预设和照片不受影响

### 高德 API

用来填你自己的高德密钥，软件不附带密钥。

- **高德地图 Key** 和 **安全密钥** 两个输入框，都支持显示/隐藏
- **测试连接**：直接问一次高德，成功会显示查到的地址，失败会说明原因
- **获取教程**：默认收起，点击展开。里面有六步：注册、实名认证、创建应用、添加 Key、**填写域名白名单**、复制两个密钥
- **有坐标时自动填地点**：默认开启

**关于域名白名单**：教程里会让填一行 `127.0.0.1`。只填这一串，不要带 `http://`，也不要带端口。

### 关于

显示软件图标、中英文名称、版本号、GitHub 仓库链接，下方是可折叠的快捷键列表。

## 本次新增：高德地点填写

### 自动填

照片带 GPS 坐标时，自动换成地名填进「地点」。

**只在需要时查询**：只有当前照片套用的预设里**包含地点组件**时才会去查。预设不需要显示地点，就不消耗你的调用次数。

**不会覆盖你填的内容**：已经手动写过地点的照片，自动功能会跳过。

**同一地点只查一次**：多张照片在同一个位置时，共用一次查询结果。

### 手动填

信息面板「地点」一栏右侧多了一个定位图标，点开是地图：

- 在地图上点一下位置
- 下方会显示该位置的地址
- 点「使用这个地点」填入

如果照片没有 GPS 坐标，就用这个方式。

### 坐标不会写进照片

从照片读出的坐标只用来查地名，**不会写回照片**。导出的照片默认仍然移除 GPS 定位信息。

## 技术说明

- 读 GPS 用的是照片里现成的 EXIF 数据，南纬西经会正确转换成负数
- 地图通过微软 WebView2 显示，页面由软件内部的本地服务提供（地址 `127.0.0.1`，端口自动选择）
- 密钥在设置文件里做了简单混淆，不是明文；但这只能防「打开文件一眼看到」，不能防专门破解
- 新增依赖：`webview_flutter_windows`、`url_launcher`、`package_info_plus`、`shelf`

## 沿用功能

- 预设分享面板：二维码、文本代码、导出 .lmp、保存图片
- 从图片导入预设（读图中的二维码，不需要摄像头）
- 删除照片后列表自动刷新
- 导出中断后续传
- 信息面板分组、「覆盖已有数据」开关
- 照片移动或改名后自动认回
- HEIC / HEIF 打开与导出，广色域照片预览与导出一致
- 成片最长边 16384 像素、总像素约 1.34 亿
