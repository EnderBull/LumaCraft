# LumaCraft 0.15.6 · 关联按钮只在需要时出现（制作版）

2026-11-06，版本 0.15.6+49。沿用 0.15.5 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次调整

- **底栏「重新关联」按钮只在确实有待关联照片时出现**，不用的时候不占位置。出现时用强调色，和普通按钮区分开。
- 自动关联成功的提示（中性底色的「已自动关联 N 张」）保持原样。

## 沿用功能

- 照片移动或改名后自动认回，套用的预设和补填的信息跟着照片走。
- 自动关联后底栏出现提示，点开能看到「原名 → 新名」的对照。
- 接不回时可手动选照片，改名也能接；多张一起选时先按拍摄时间自动配对待确认。
- 关联面板点面板以外区域即关闭。
- 记住窗口位置和大小，下次打开回到原处；拔掉外接显示器会退回主屏。
- 浏览和编辑两个模式的底栏都有重新关联入口。
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致。
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸。
- 导出中软件卡住或自己退出，下次打开说明原因；自己关窗口则不提示。
- 没装 HEIC 解码时，提示下有两个按钮直接打开微软商店。
- 手机常见 HDR 用其中的普通画面；整张按高亮度编码的 HDR 暂不支持，会说明原因。
