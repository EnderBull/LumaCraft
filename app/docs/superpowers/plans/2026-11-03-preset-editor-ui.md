# 预设编辑器原型实施计划

**Goal:** 在现有工作台风格下提供可操作的编辑器原型供用户确认。

**Architecture:** 独立 HTML/CSS/JS 页面；JSON 草稿驱动 SVG 预览，照片选择与草稿编辑分离；历史保存文档快照，浏览器本地存储保存草稿和用户预设。

**Tech Stack:** 原生 HTML、CSS、JavaScript、SVG、localStorage。

- [x] 实现 SVG 画布、锚点、文字组件、图层和属性操作。
- [x] 实现历史、应用范围、预设另存、草稿恢复及快捷键。
- [x] 增加工作台入口；运行一轮核心交互检查，记录结果。

- [x] 共同属性与六方向对齐，拖动吸附辅助线及 Alt 开关。
- [x] 模型检查及一轮浏览器核心操作验证，修正发现问题。
Ruling: 图层层级与文本组件分开保存，并根据层级生成绘制顺序 — 分组无需改写组件内容，且能兼容既有记录 — 新增 editor-objects.js 维护该逻辑。
