# Windows 预设编辑器接入（已获用户确认）
日期：2026-11-04

范围：沿用浏览器原型，接入真实照片、图层/分组、属性、历史、坐标与吸附、缩放平移、预设新建/覆盖及明确应用范围。保留无边框窗口。兼容旧照片样式，不删除旧版本。采用 Flutter 原生文字排版，同一排版服务用于预览与导出，背景处理保留 EXIF、默认不复制 GPS。

1. lib/editor/style_document.dart：JSON 样式模型、树结构、比例几何及锚点换算。
2. lib/editor/editor_controller.dart：历史、选择、分组、重排和对齐；lib/editor/preset_store.dart：用户预设和草稿文件保存。
3. lib/editor/style_render.dart：共享 TextPainter 文字测量、绘制、导出像素；render.dart：后台编码和元数据。
4. lib/ui/editor/：原生画布、图层、属性、预设及主界面；复用 WorkspaceLayout、目录和滚动基础能力。
5. main.dart、photo_state.dart：入口、真实照片/信息、应用样式、预览及导出；pubspec.yaml：新版本。
6. 单轮核心检查：样式持久化/分组/历史、真实照片编辑→新建/覆盖预设→应用→导出和 EXIF，编译新 dist 包。其余体验交用户验证。

兼容策略：旧 film 字段仍可读取；只有新样式字段存在时才走可编辑样式。内置模板不可覆盖。草稿保存不自动改变照片。视图变换不写入文档历史。存储错误显示，不假报成功。


## 同日追加的已确认界面范围
- 顶栏共用“浏览 / 编辑”分段开关，移除侧栏旧入口；按来源样式保存草稿，模式切换不自动应用。
- 浏览页将照片信息固定到导出按钮上方，预设与信息各自滚动；用户预设也在浏览页可选择。
- 标签页使用原型底部强调色线条；保存/应用使用相同的圆角矩形、高度与排列。
- 图层与组件工具图标直接从原型导出为 SVG，使用 flutter_svg 的原生矢量绘制路径；不使用低分辨率截图做图标。
- 属性控件按照原型成组排列，单位位于输入框内、颜色色块嵌入、对齐使用分段按钮、透明度滑条。
- 顶栏和底栏交界阴影使用不会拦截指针的覆盖层，避免被后绘制的侧栏背景遮住。
