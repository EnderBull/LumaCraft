# 照片色卡实施计划

已获用户确认，先交付照片色卡，图片标识与背景填充留下一批。使用 writing-plans / executing-plans 技能执行。

范围：自动提取原照片六种代表色，兼顾占比与差异，按明度排序可反转。独立色块支持圆形、圆角矩形、圆角六边形；连续色条六等分、整体圆角。尺寸、间距、圆角、内描边粗细与颜色可调，色条整体或逐块描边。沿用组件选择、移动、缩放、对齐、分组、保存、撤销与导出。

文件：新增 lib/editor/photo_palette.dart（固定小图提色及文件缓存）、palette_style.dart（可序列化属性）、palette_render.dart（形状与绘制）；修改 style_document.dart、style_render.dart、editor_canvas.dart、editor_panels.dart、editor_page.dart、main.dart；新增色卡 SVG 图标；核心测试、版本和交付文档。

- [x] 数据与提色：固定最长边96px从原文件提色，后台量化与代表色选择，缓存按文件路径/长度/修改时间；照片不足六种颜色时允许重复，不生成额外颜色；预设只存布局规则。
- [x] 共用绘制：独立形状与连续色条，内描边、圆角限制、避免重复分隔线；预览与导出读取相同六色结果；选区边界统一。
- [x] 原生面板：独立/色条与形状选框、按形态显示属性、多选只显示共同设置、透明度、缩放与位置；图标沿用圆角线条/暖金细节。
- [x] 一轮核心验证：提色与单色、属性存储/撤销、形状绘制与导出、旧文字编辑兼容；只读审查后修复重要问题，编译并打包0.3.0试用版。

实现决定：六边形为正六边形，边长控制尺寸；圆角矩形宽高独立。整体缩放通过独立倍率同时影响色块、间距、圆角和描边。所有几何均按原照片短边1000px的既有规则。形状切换保留属性，只显示当前形态相关项。提色失败明确提示重试，不伪造色块。
