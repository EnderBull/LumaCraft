# 共用预设管理与 .lmp 分享实施计划

> 使用 superpowers:executing-plans 在当前工作区顺序执行。用户已确认方案与文件范围，无需重复确认。

**目标：** 浏览与编辑使用相同预设面板；单击、Ctrl、Shift、框选，首选应用、多选不重复套用；用户预设管理、单层分组及 .lmp 单个/批量离线分享。
**结构：** PresetStore 保存分组元数据，保持旧记录兼容；PresetSelection 仅存管理选区；共用 PresetPanel 接收应用回调。分享格式有标识和版本，携带样式及内嵌图片，不携带照片/EXIF/草稿/本地路径。
**技术：** 现有 Flutter、file_selector，不新增依赖。仅交付可运行文件夹。

## 任务与文件
- 扩展 app/lib/editor/preset_store.dart：用户预设所属分组、分组列表、原子保存、统一管理操作。新增 preset_selection.dart：多选及首选应用状态；保留内置不可覆盖/删除。
- 新增 app/lib/editor/preset_package.dart：.lmp 标识/版本/能力检查、样式和嵌入素材校验、分享及导入合并；同名保留两份/覆盖/跳过，默认保留两份，导入完整校验后一次写入。
- 新增 app/lib/ui/preset_panel.dart 与 preset_actions.dart：共用搜索、筛选、组选择、缩略图、悬停半透明强调框/选中实色框、更多及右键菜单、固定多选动作。删除组需选保留或连带删除；多选禁重命名，仅复制/移动/导出/删除。
- 修改 app/lib/main.dart 和 app/lib/ui/editor/editor_panels.dart/editor_page.dart：接入同一面板，保存时选组；浏览应用照片，编辑只载入草稿；新增空白样式入口。
- 新增 app/test/preset_library_test.dart：多选回调次数、框选、文件往返/图片持久、同名规则、分组删除两条路径、损坏文件不修改库，以及共用面板交互。更新现有测试假存储以保持接口。
- 更新产品说明、版本、交付文档；运行一轮相关核心流程及只读审查，构建输出 0.5.0 文件夹，不生成压缩包、不删除旧文件。

## 明确规则
- .lmp 为自定义格式，内含 LumaCraft 标识与版本；单个、选中批量、整组都输出同一种文件。
- 分组单层，默认“未分组”；删除组弹窗默认保留预设，可主动选同时删除。
- 原照片已应用效果不随管理操作变动；导入只加入库，不自动套用。
- Ctrl/Shift 后续增减不套用；无选区起始框选按显示顺序取首项，松鼠标才套用一次；普通单击重新套用。
- 内置允许复制及导出，多选含内置时移动/删除禁用，避免部分静默执行。
- 分享导入前显示样式缩略图及数量；整体检查通过并完成冲突选择后才原子写入。

## 检查重点
- 自动草稿保存不能覆盖分组变更；操作失败不提前更新内存状态。
- 改名/移动/删除不影响照片样式副本，覆盖保留本地预设身份及收藏。
- 无效引用、循环分组、未知样式能力、损坏素材、过大文件均拒绝，避免部分导入。
- 弹窗/菜单/搜索输入不把快捷键泄漏到画布或照片选择。
- 大量预设缩略图使用现有解码缓存，框选只更新选择边框，不连续应用样式。
