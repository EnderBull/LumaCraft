# 横竖独立布局

已获用户确认。默认统一布局，可启用横竖独立；方图使用通用布局。

1. 通用样式保存共享内容与基础布局，横图/竖图仅保存布局差异。位置、锚点、字号、尺寸、间距、对齐、可见性及边框独立；素材、内容、字体、颜色、背景、投影、打孔与图层结构共享。
2. 画布属性提供布局切换、从通用复制及恢复通用。构图模拟不改变导出比例；越界仅提示。
3. 预设提供横竖通用、横图优先、竖图优先标记及筛选。保存、草稿、离线分享、预览和导出共用解析。
4. 旧样式默认统一布局。分享包声明横竖布局能力，旧版拒绝不支持的包。
5. 一轮核心验证：横竖编辑、共享属性、撤销、保存/重开、分享、混合构图渲染。构建 Windows 可运行文件夹，不生成压缩包。
