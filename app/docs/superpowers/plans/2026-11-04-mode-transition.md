# 浏览与编辑模式切换实施计划

用户已选择并授权“侧栏轻滑，画布保留”。使用 writing-plans 和 executing-plans 技能执行。

目标：取消整页缩放和整页淡入淡出。顶栏和底栏保持相同位置，侧栏在裁剪区域内移动 16 px；侧栏与画布进入/退出统一 260 ms，使用 easeInOutCubic 柔和起停，反向返回亦保持平滑。按用户最新确认，仅左右侧栏内容叠加同节奏的淡入淡出。照片通过共享画布元素平滑适配位置和尺寸，不参与透明度变化。下拉菜单继续无动画。

文件：main.dart 负责无整页动画的路由、状态往返；editor_page.dart 负责预载照片、状态回传；editor_canvas.dart 和 style_render.dart 提供共享画布；新增 ui/editor/mode_transition.dart 集中路由、侧栏动画和画布标识；核心测试及版本、交付说明。

- [ ] 实现无整页转场的模式路由及局部侧栏移动，尊重系统减少动画设置。
- [ ] 共享照片画布，不重复等候解码；进入和返回保留当前照片、多选和底栏滚动位置。
- [ ] 核心流程一轮检查，聚焦模式往返、未应用草稿、图片所有权、弹层快捷键与快速切换；原生查看后编译打包 0.2.3。

约束：不删除旧包，不改原照片，不做额外动画或广泛测试。已有草稿与已应用样式不同，内容应在切换时展示各自真实状态，不使用透明度混合掩盖差异。
