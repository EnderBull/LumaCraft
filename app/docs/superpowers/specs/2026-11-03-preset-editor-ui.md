# 预设编辑器交互原型

用户已确认在当前工作台就地编辑的方案。本轮仅制作浏览器交互原型，Windows 程序和照片文件不变。

## 布局与操作
保留 54 px 顶栏、黑金主题、两种布局、面板拖拽和照片底栏。左栏“图层 / 目录”切换；中央 SVG 画布点选、拖动、缩放文字组件并显示对齐辅助；右栏根据选择显示画布或组件属性。右侧提供取消选择返回画布设置的入口。

初始含题签、摄影参数和作者三个独立组件。支持自由文字、作者、参数组合、设备、镜头、时间、地点等内容；可变字段从当前演示照片读取，缺失时隐藏并说明。可隐藏、锁定、复制、删除和调整图层顺序。边框四边比例基于照片短边，可联动，背景为纯色。

编辑草稿全局用于当前工作会话预览；切换演示照片仅检查内容和比例适配，不暗中应用。组件以画布、照片或下边框为锚定区域，保存比例位置。拖动或连续控件输入合并为一次历史操作。撤销、重做、恢复本次编辑前、恢复原始模板独立命名。

“应用”明确选择当前照片或选中照片；“保存预设”只保存样式，支持新建或明确选择用户预设覆盖，不自动应用。保留内置模板。草稿和用户预设在浏览器本地持久保存，存储失败显示提示。横/竖/方预览为适配检查，不裁改文件。原型使用现有示例图，不读取用户磁盘，不导出成片。

## 文件职责
- app/ui-prototype/editor/index.html：界面结构和可访问控件。
- editor.css：视觉样式、布局、拖拽手柄和滚动表现。
- editor.js：草稿模型、SVG 排版、选择历史、属性编辑及浏览器保存。
- app/ui-prototype/index.html：编辑器入口。
- app/ui-prototype/design-notes.md：本次原型范围和验证结果。

## 验证
一轮核心流程：调整边框、添加和拖动文字、调整属性、隐藏/锁定/排序、撤销重做、多选和切图、明确应用范围、另存与恢复草稿；检查横/竖/方、两种布局和面板拖拽。其余操作体验交用户确认。


## 已确认的编辑器交互调整
- 图层行支持鼠标拖动排序，提供插入线及边缘滚动，拖动完成作为一次撤销操作；保留上下移按钮。
- 右侧顶部使用“预设 / 画布 / 组件”文字页签与金色下划线；初始进入预设页，选择组件自动进入组件页，点画布空白进入画布页。组件页未选中时显示选择提示。
- 预设选择集成在右侧，使用当前演示照片生成真实布局缩略图，提供名称搜索与全部/内置/我的筛选。点击卡片仅载入草稿，顶栏预设名称也打开此页，不再使用只有标题的选择弹窗。
- “保存预设”与“应用样式”并排位于右侧栏底部固定区域。
- 画布上双击自由文字或作者固定文字，进入原位编辑；Enter 换行，点击外部或 Ctrl+Enter 完成，Esc 取消。一整次编辑记录为一次撤销，照片动态字段继续从照片信息提供内容。锁定组件不可编辑。
- 字体选择框与字号/字间距行间距为 17 px，其余相关控件间距同步统一。


## 2026-11-04 多选、分组与自动对齐
用户已确认合并制作自动对齐、多选和 PS 式图层分组。新增 editor-objects.js，将组件层级/选择与既有文字模型分离，原有草稿和预设读取时补齐 order/groups，不把旧组件合并或丢弃。组支持嵌套，保留独立组件内容、锚点和排版属性，图层绘制顺序由层级顺序生成。
图层面板普通点击单选、Ctrl 增减、Shift 连选，Ctrl+Shift 追加范围；画布点击选中组件或所属组，从空白处拖动选框全包含选中，Ctrl/Shift 框选追加。隐藏或锁定组件不参与框选，展开组后可在图层中单独编辑成员。
多选和组支持整体拖动、共同文字属性修改、复制、删除及六方向对齐。差异属性显示多个值，只应用实际输入的属性；锁定选区不进行整体编辑。画布拖动仍遵守组件原有锚定区域，整体位移统一约束，避免单独夹断导致组内部相对位置变化；单组件保留右下角缩放。
Ctrl+G 分组，Ctrl+Shift+G 取消分组。左栏和组件面板提供按钮；组可命名、折叠/展开、隐藏/锁定，成员继承组状态。分组、解组、拖动、排序和批量编辑各作为一次撤销操作。组中成员独立编辑不影响其他成员的内容。
自动吸附使用实际文字包围框与选区/组边界，阈值为屏幕 6 px；支持左右、上下和水平/垂直中心，优先同类边缘或中心，兼容相邻边缘贴合。显示对应辅助线，可用顶栏按钮关闭或按住 Alt 临时关闭。隐藏组件不作为参考，锁定组件仍可参考。

## 保存/应用入口的最新确认
草稿提示在主面板上方居中，14 px、中性色圆角背景；与吸附提示分开。右栏底部“保存预设”为中性色、“应用样式”为强调色，两者等宽等高。保存弹窗列出全部用户预设及缩略图，可新建或明确覆盖既有用户预设，默认新建，内置模板不可覆盖，取消不写入；按钮分别标明新建保存/覆盖保存。应用样式独立选择当前或选中照片。添加组件菜单与图层面板复用同一套双色矢量图标。
