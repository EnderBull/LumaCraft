# LumaCraft 0.15.3 · 记住窗口位置、编辑模式也能重新关联（制作版）

2026-11-06，版本 0.15.3+46。沿用 0.15.2 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次新增

- **记住窗口位置和大小**：关掉软件时记下当时的窗口位置、大小和是否最大化，下次打开回到原处。
  拔掉外接显示器后，如果记录的位置已经不在任何屏幕上，会自动回到主屏，不会开到看不见的地方。
- **编辑模式底栏也有「重新关联照片」按钮**，和浏览模式一致。两个模式共用同一个底栏组件，入口不再只在浏览模式出现。
- **关联面板里「选择其他文件…」按钮一直在**。之前没有可关联照片时按钮会消失，现在始终显示，随时能手动挑照片。

## 沿用功能

- 照片改名或对调名字后，预设和补填的信息跟着照片内容走，不跟文件名。
- 照片搬到别的文件夹后按文件名和拍摄时间自动接回；接不回可手动选择，改名也能接。
- 多张一起手动选时，先按拍摄时间自动配对待确认，左栏只留还需手动配的。
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致。
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸。
- 导出中软件卡住或自己退出，下次打开说明原因；自己关窗口则不提示。
- 没装 HEIC 解码时，提示下有两个按钮直接打开微软商店。
- 手机常见 HDR 用其中的普通画面；整张按高亮度编码的 HDR 暂不支持，会说明原因。
