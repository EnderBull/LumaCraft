# LumaCraft 0.16.0 · 导出中断后可以接着导（制作版）

2026-11-06，版本 0.16.0+50。沿用 0.15.6 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次新增

- **导出中断后可以接着导。**
  导出时会记下这一批还剩哪些照片、已经完成几张。如果软件卡住或自己退出，下次打开会说明是哪一张停住的，并给出「继续导出剩下的 N 张」。
- **会跳过中断时正在处理的那一张。** 它最可能就是停住的原因；跳过它，这一批就一直往前走，不会反复卡在同一张照片上。
- 上次已经失败过的照片、已经不存在的照片也会跳过；已经导出成功的不会重做。
- 只有一张照片的那批，如果就是它中断了，会直接说明「已跳过，没有需要继续导出的照片」。
- 自己关掉窗口不算中断，下次打开不会提示。

## 沿用功能

- 照片移动或改名后自动认回，套用的预设和补填的信息跟着照片走；自动关联成功时底栏有提示。
- 底栏「重新关联」按钮只在确实有待关联照片时出现，用强调色显示。
- 接不回时可手动选照片，改名也能接；多张时先按拍摄时间自动配对待确认。
- 关联面板点面板以外区域即关闭。
- 记住窗口位置和大小，下次打开回到原处；拔掉外接显示器会退回主屏。
- 浏览和编辑两个模式的底栏都有重新关联入口。
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致。
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸。
- 没装 HEIC 解码时，提示下有两个按钮直接打开微软商店。
- 手机常见 HDR 用其中的普通画面；整张按高亮度编码的 HDR 暂不支持，会说明原因。

## 说明

- 这是制作版。改过的内置预设要点“保存预设”，才会写进制作版工作库。
- 内置预设已定稿，开发阶段不再修改，也不封包；第一个正式版完成后再统一封包。
