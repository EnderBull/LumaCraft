# LumaCraft 0.17.0 · 拍摄信息就地补填、导出进度分数（制作版）

2026-11-06，版本 0.17.0+53。沿用 0.16.2 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次调整

- **导出进度右下角显示「已导出 / 总数」**，例如 `3 / 30`，同时保留进度条。
- **浏览模式的信息面板改成直接可填。** 原来要点「查看 / 补填选中 N 张信息」再开二级窗口，现在信息面板本身就是表单，
  不再需要二级弹窗。
- **信息表单统一为固定版式**，顶部一个「覆盖已有数据」开关：
  - 开关关闭（默认）：照片已有的项显示在输入框里、置灰不可改；缺的项可以直接填。
  - 开关打开：所有项都能改写。
  - 都只保存在软件内，不会改动照片文件。
- **编辑模式的组件面板支持就地补填。** 选中相机、镜头、焦距、光圈、快门、ISO 这类拍摄信息组件时，
  属性面板里会出现对应输入框（相机与镜头并排、焦距与光圈并排、快门与 ISO 并排）。
- **编辑模式在没选中任何组件时**，右侧属性面板显示整张照片的拍摄信息表单，规则与浏览模式一致。

## 沿用功能

- 文件夹里任何变化（新增、删除、改名）都会自动刷新，当前照片被删会跳到相邻一张并提示。
- 应用样式只选中一张时直接生效，多张才弹范围对话框。
- 导出中断后可以继续导出剩下的照片，跳过中断那张和上次失败的，不重复已完成。
- 照片移动或改名后自动认回，预设和信息跟着照片走；自动关联成功时底栏有提示。
- 底栏「重新关联」按钮只在有待关联照片时出现。
- 记住窗口位置和大小，下次打开回到原处。
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致。
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸。
- 没装 HEIC 解码时，提示下有两个按钮直接打开微软商店。
