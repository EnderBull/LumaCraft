# LumaCraft 0.14.1 · 质感分组、预设数字、邮戳取色（制作版）

2026-11-06，版本 0.14.1+42。沿用 0.14.0 的全部功能。内置预设已换成你今天在制作版里保存的版本，并做了下面的分组整理。

## 分组

- “纸张手帐”改名为“质感”。软件内部仍用原来的分组编号，已经保存的预设不会因此对不上。
- “大理石画廊”从“简约”挪到“质感”，放在这一组最后。
- 其它预设还在原来的组里。现在仍是 9 组、41 款。

## 操作

- 图层列表里，点一行的任何位置都会马上选中，包括文字旁边的空白和左侧的拖动手柄。要拖动排序，需要按住并挪开大约 20 像素。轻轻点一下，手有一点晃动时，也只是选中。
- 组件上的数字框，双击回到打开这套预设时的数字。正在看横图就回到横图当时的数字，竖图同理。编辑过程中新加的组件（包括复制出来的），回到它刚出现时的数字。一次双击记一步撤销；多选时，每个组件回到各自的数字。
- 画布上的边框、填充、阴影、照片描边、胶片、邮票、纹理这些数字，双击仍回到软件最初给的默认值。
- 邮戳墨色仍有灰、蓝、红、黑四个快捷色。旁边的色块打开取色板，可以选任意颜色。只改颜色时，邮戳大小不变；换一种邮戳样式时，用那种样式自己的默认大小。以前做好的灰蓝红黑邮戳还能照常认出。
- 选中组件后按住方向键移动：从按下到方向键全部松开，算一步。中途换方向，或按着 Shift 加大步子，还是这一步。松开后再按，才是新的一步。点一下方向键，也是一步。组件被锁定时，方向键不会把它移走。
- 窗口最大化后，画面四周收在屏幕里面，不再被裁掉一圈。还原成普通窗口后，边缘仍可拖动改变大小。

## 说明

- 这是制作版。改过的内置预设要点“保存预设”，才会写进制作版工作库。
- 文字在 Windows 缩放后是否清晰，需要你在自己的屏幕上看一眼。
