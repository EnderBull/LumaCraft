# LumaCraft 0.17.1 · 修删除刷新与导出恢复，信息面板分组（制作版）

2026-11-06，版本 0.17.1+54。沿用 0.17.0 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次修正

- **文件夹里的删除现在会刷新列表了。** 之前只在「照片数量变化」时才更新，所以删一张又加一张（数量不变）时什么都不动；
  现在按实际有哪些照片比对，删掉的就从列表里消失，当前那张被删会跳到相邻一张并提示。
- **导出中断后能恢复提示了。** 之前你正常关一次窗口会留下一个「主动关闭」标记，之后所有崩溃提示都会因为这个标记被忽略。
  现在每次开始导出会清掉该标记，任务管理器结束进程后重新打开就能看到提示并继续导出。
- 编辑模式也加了保护：扫描意外返回空结果时不会把列表清空。

## 信息面板排版

- 分成三组，带图标和标题，层次更清楚：
  - **设备**：相机型号、镜头型号（各占一行，型号通常较长）
  - **曝光参数**：焦距与光圈一行、快门与 ISO 一行
  - **时间与地点**：拍摄时间、地点各占一行
- 每项是一个卡片：标签小、值醒目；已锁定、可填写、缺失三种状态外观不同。
- 「覆盖已有数据」开关缩小了尺寸，与文字之间留出了间距。
- 开关关闭时，照片已有的项显示为带锁图标的只读卡片，和「可填写的空项」一眼就能分开。
- 校验提示改为「信息格式错误或无效」，且开关开启和关闭时都会显示（有些照片文件本身的 Exif 格式就有问题）。

## 沿用功能

- 导出进度右下角显示「已导出 / 总数」。
- 浏览与编辑共用同一个拍摄信息表单，不再有补填二级弹窗。
- 编辑模式选中信息组件可就地补填；未选中组件时显示整张照片信息。
- 应用样式只选中一张时直接生效，多张才弹范围对话框。
- 照片移动或改名后自动认回，预设和信息跟着照片走。
- 记住窗口位置和大小，下次打开回到原处。
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致。
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸。
