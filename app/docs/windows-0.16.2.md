# LumaCraft 0.16.2 · 删除照片会刷新、应用样式更省一步（制作版）

2026-11-06，版本 0.16.2+52。沿用 0.16.1 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次调整

- **文件夹里的任何变化都会自动刷新**，不只是新增。删除、改名也会立刻反映到列表里。
  删除照片后，如果被删的正好是当前选中那张，会自动跳到最近的一张，并在底栏说明「N 张已不在文件夹里」，不会留下一个空白画面。
- **应用样式少一步**：只选中一张照片时，点「应用样式」直接生效，不再弹范围对话框；选中多张时仍然会问「仅当前照片 / 选中照片全部」。

## 沿用功能

- 当前目录有新增照片会自动出现（含子目录，连续写入合并为一次刷新）。
- 导出中断后可以继续导出剩下的照片，跳过中断那张和上次失败的，不重复已完成。
- 照片移动或改名后自动认回，预设和信息跟着照片走；自动关联成功时底栏有提示。
- 底栏「重新关联」按钮只在有待关联照片时出现，用强调色；接不回可手动选照片，改名也能接。
- 关联面板点面板以外区域即关闭。
- 记住窗口位置和大小，下次打开回到原处；拔掉外接显示器会退回主屏。
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致。
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸。
- 没装 HEIC 解码时，提示下有两个按钮直接打开微软商店。
- 手机常见 HDR 用其中的普通画面；整张按高亮度编码的 HDR 暂不支持，会说明原因。

- 内置预设已定稿，开发阶段不再修改，也不封包；第一个正式版完成后再统一封包。
