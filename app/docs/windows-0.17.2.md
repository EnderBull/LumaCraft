# LumaCraft 0.17.2 · 删除刷新与导出恢复真正修好、重名新增「跳过同名」（制作版）

2026-11-06，版本 0.17.2+55。沿用 0.17.1 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次修正

- **删除照片现在一定会刷新。** 之前只靠 Windows 的文件变化通知，删除到回收站时它可能完全不通知。
  现在除了通知，还每两秒核对一次文件夹，发现少了就立刻更新列表；当前编辑的那张被删会跳到相邻一张并提示。
- **导出中断一定会提示。** 两个原因都修了：
  - 进度记录原来是直接覆盖写的，进程被强杀时可能只写了一半，读出来是坏的、被当成「没有导出」静默清掉。
    现在先写临时文件再替换，不会写坏。
  - 现在**不管上次是自己关的窗口还是意外崩溃，都会提示**，由你决定是否继续导出；
    两种情况的说明文字不同，但都能选「继续导出剩下的 N 张」。

## 重名处理

- 新增「跳过同名」：输出目录里已有同名文件的照片直接跳过，已有的文件不动。
- 按钮配色：**替换保存**、**跳过同名**用强调色；**全部保留**用淡红色；**取消导出**保持中性色。

## 沿用功能

- 信息面板按「设备 / 曝光参数 / 时间与地点」分组；相机与镜头各占一行。
- 「覆盖已有数据」开关默认关闭，关闭时已有项锁定不可改、缺失项可直接填。
- 校验提示「信息格式错误或无效」在开关开或关时都显示。
- 导出进度右下角显示「已导出 / 总数」。
- 浏览与编辑共用同一个拍摄信息表单。
- 照片移动或改名后自动认回，预设和信息跟着照片走。
- 记住窗口位置和大小。
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致。
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸。
