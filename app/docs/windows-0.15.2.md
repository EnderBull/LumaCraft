# LumaCraft 0.15.2 · 改名、对调后样式仍跟着照片（制作版）

2026-11-06，版本 0.15.2+45。沿用 0.15.1 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次修正

- **照片换了名字或对调名字，套用的预设和补填的信息会跟着照片本身走**，不再按文件名认。
  软件给每张照片记一个内容指纹（文件大小加开头结尾各一小段的校验值），文件内容一换就能看出来，
  记录随之挪到新位置。
- **在同一文件夹里给照片改了名字，也能识别出来。** 会出现在「待关联」里，可以手动接回。
- **底栏的「重新关联照片」按钮现在一直都在**，不再需要先有失联记录才出现。
  没有待处理的记录时会提示「当前文件夹的照片都有记录」。

## 沿用功能

- 照片搬动到别的文件夹后，按文件名和拍摄时间自动接回记录。
- 接不回时可手动选照片，改名也能接；一次选多张时先按拍摄时间自动配对待确认，左栏只留还需手动配的。
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致。
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸。
- 导出中软件卡住或自己退出，下次打开说明原因；自己关窗口则不提示。
- 没装 HEIC 解码时，提示下有两个按钮直接打开微软商店。
- 手机常见 HDR 用其中的普通画面；整张按高亮度编码的 HDR 暂不支持，会说明原因。

- 内置预设已定稿，开发阶段不再修改，也不封包；第一个正式版完成后再统一封包。
