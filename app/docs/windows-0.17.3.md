# LumaCraft 0.17.3 · 删除刷新真正修好、所有弹窗点外部即关闭（制作版）

2026-11-06，版本 0.17.3+56。沿用 0.17.2 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次修正

- **删除照片现在真的会刷新了（浏览和编辑模式都已验证）。** 上一版声称修好但编辑模式仍然无效，
  这次查到三个真实原因：
  - 编辑模式刷新时把照片列表整块替换，程序当场报错，后面的刷新全部中断；错误又发生在后台，
    界面上完全看不到痕迹。
  - 删掉照片时缩略图被立刻销毁，但界面还在用它，随即出错，画面停在旧状态。
  - 预览解码时打开的文件没有关紧，照片会被软件占用一段时间，甚至删不掉。

  现在这四处都改了，并且补了会真正删照片、等几秒、再查界面数量的自动测试，浏览与编辑各一项。

- **删除到回收站也能刷新。** 用真实的「移到回收站」操作验证过，列表和底栏会立刻减少，
  当前照片被删会跳到相邻一张并提示。

- **所有弹窗点外部即可关闭。** 之前导出中断提示和重名对话框只能点按钮关闭，和软件其它面板不一致。
  现在统一为：点击面板外的软件区域直接关闭，等同于「暂不处理 / 取消」，不会执行任何破坏性动作。

## 导出中断提示（本次重点修复）

上一版说「关窗口或崩溃都会提示」，实际两种情况都没有提示。原因是窗口关闭那段底层代码里还留着旧逻辑：
只要点了关闭按钮（任务管理器的「结束任务」也会先发这个关闭信号），就会**把进度记录直接删掉**，
所以下次打开什么都没有可提示的。

现在改为：

- 关闭窗口**只留一个说明标记，绝不删除进度记录**。
- 没在导出时关窗口不会留标记，以后真崩溃时不会被误说成「你自己关的」。
- 一批导出处理完（导完、续导完、选了暂不导出）后，标记和记录一起清掉。
- 两种情况都会提示，措辞不同：
  - 点 X 关闭：「软件在导出过程中被关闭了」；
  - 任务管理器强杀或闪退：「软件自己停住了，不是正常关闭」。

实测确认：点 X 关闭后记录仍在、重新打开会弹出提示；强杀后记录仍在、按崩溃措辞提示；
没在导出时关窗口不会误留标记。

## 性能说明

- 为应对「删了照片软件没反应」加的后台文件夹核对保留了，但间隔由每 2 秒放宽到每 5 秒。
  实测开销：200 张约 1.3 毫秒，2000 张约 2.6 毫秒，1 万张约 16.6 毫秒，
  40 个子目录共 6000 张约 17.5 毫秒。且只读文件名，没变化就不重读照片，平时几乎察觉不到。
- 实测确认：彻底删除、删除到回收站、改名、移出文件夹，这四种情况 Windows 都会通知软件。
  保留定时核对是为了应对一次复制几百张、网络盘、云同步文件夹这几种通知可能漏掉的情况。

## 重名处理

- 新增「跳过同名」：输出目录里已有同名文件的照片直接跳过，已有的文件不动。
- 按钮配色：**替换保存**、**跳过同名**用强调色；**全部保留**用淡红色；**取消导出**保持中性色。

## 沿用功能

- 导出中断后，不管上次是自己关的窗口还是意外崩溃，都会提示并可由你决定是否继续导出。
- 信息面板按「设备 / 曝光参数 / 时间与地点」分组；相机与镜头各占一行。
- 「覆盖已有数据」开关默认关闭，关闭时已有项锁定不可改、缺失项可直接填。
- 校验提示「信息格式错误或无效」在开关开或关时都显示。
- 导出进度右下角显示「已导出 / 总数」。
- 浏览与编辑共用同一个拍摄信息表单。
- 照片移动或改名后自动认回，预设和信息跟着照片走。
- 记住窗口位置和大小。
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致。
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸。
