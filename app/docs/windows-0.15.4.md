# LumaCraft 0.15.4 · 关联提示不再误报、面板点外面即关（制作版）

2026-11-06，版本 0.15.4+47。沿用 0.15.3 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次修正

- **改名后已经自动接回，底栏却还提示「重新关联」的问题已修好。**
  之前只要旧记录曾经在这个文件夹里，就一直算作待关联；现在只有文件夹里确实存在「还没有自己记录、并且文件名或拍摄时间能对上」的照片时，才提示。
- **关联面板改为点面板以外的窗口区域就关闭**，和其他面板的操作习惯一致。

## 本次新增（上一版）

- 记住窗口位置和大小，关闭时记下，下次打开回到原处；拔掉外接显示器会退回主屏。
- 编辑模式底栏也有「重新关联照片」按钮。
- 关联面板「选择其他文件…」按钮常驻，随时能手动挑照片。

## 沿用功能

- 照片改名或对调名字后，预设和补填的信息跟着照片内容走，不跟文件名。
- 照片搬到别的文件夹后按文件名和拍摄时间自动接回；接不回可手动选择，改名也能接。
- 多张一起手动选时，先按拍摄时间自动配对待确认，左栏只留还需手动配的。
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致。
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸。
- 导出中软件卡住或自己退出，下次打开说明原因；自己关窗口则不提示。
- 没装 HEIC 解码时，提示下有两个按钮直接打开微软商店。
- 手机常见 HDR 用其中的普通画面；整张按高亮度编码的 HDR 暂不支持，会说明原因。

- 内置预设已定稿，开发阶段不再修改，也不封包；第一个正式版完成后再统一封包。

- 以后每次更新都会开一个新的小版本文件夹，不覆盖旧版本。
