# LumaCraft 0.17.4 · 预设分享与从图片导入（制作版）

2026-11-07，版本 0.17.4+57。沿用 0.17.3 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次新增：分享预设

预设右键菜单里的「导出 .lmp」换成了「分享预设」，打开一个专门的面板：

- 左边是预设预览大图，右边是二维码和文本代码
- 二维码下面标着「用**框印工坊**扫码导入」，软件名用强调色
- 文本代码框内嵌「复制」按钮，代码长度和字节数标在框的上方
- 底部四个按钮：导出 .lmp、保存图片、复制代码、取消
- 顶部左侧是软件图标和中英文名，中间是「分享预设」标题，右侧是预设名

**文本代码有多短**：去掉所有等于默认值的字段再压缩，一个普通边框从 1474 字符降到 318。实测 41 个内置预设全部能装进二维码（不包含图片标识时）。

**关于图片标识**：带图片的预设体积会到 100 KB 以上，二维码装不下。顶部有「包含图片标识」开关，默认关闭——关闭时对方拿到的是空白图片位，可以自己替换。

**保存图片**：截取面板但不含底部按钮栏，下边缘带圆角。截图时自动隐藏开关和代码提示文字，画面更干净。

## 本次新增：从图片导入

预设面板右上角菜单 → 「导入预设」，现在打开一个专门的导入面板：

- 上方两个图标按钮：从文件导入（.lmp）、从图片导入（自动读二维码）
- 下方是文本代码输入框，可直接粘贴
- 三种方式最终都走同一个确认界面，显示缩略图并处理重名

**从图片导入不需要摄像头**：选一张分享图片，软件自己找出里面的二维码并读出内容。实测用真实保存的分享图（1086 字符的高密度码），约 0.3 秒识别完成。

## 本次修正

- **高密度二维码的绘制改为整数像素对齐**。之前每个格子的边缘落在半个像素上，模糊边界让识别变困难。现在格子边界取整、关掉抗锯齿。
- **识别算法重做**：先精确裁出二维码本体，补一圈干净的纯白边，再按几档尺寸逐个尝试。直接扫描整张面板会失败，因为白色卡片的圆角会干扰定位图案的识别。
- **所有二级面板统一底色和文字颜色**，浅色模式下不再有白字压浅底。
- **次级文字颜色加深**（浅色模式 `#766e63` → `#625a4f`），各处半透明文字统一为 72% 不透明度，正文对比度全部达到可读标准。

## 沿用功能

- 删除照片后列表自动刷新（浏览和编辑模式都已验证，含回收站删除和彻底删除）
- 导出中断提示：主动关闭和意外崩溃都会提示，由你决定是否继续
- 重名对话框的「跳过同名」与按钮配色
- 信息面板分组、「覆盖已有数据」开关
- 导出进度显示「已导出 / 总数」
- 照片移动或改名后自动认回预设和信息
- 记住窗口位置和大小
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸
