# LumaCraft 0.16.1 · 目录有新增照片会自动刷新（制作版）

2026-11-06，版本 0.16.1+51。沿用 0.16.0 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次调整

- **正在查看的文件夹里新增了照片，会自动刷出来。**
  以前要从别的目录切回来才看得到，现在软件会留意当前文件夹，新增照片出现后自动读取，不用手动切换。
- 开了「含子目录」时，子文件夹里新增的照片也会自动出现。
- 一次复制很多张时，会等复制完再统一刷新一次，不会反复读盘。
- 刷新只追加新照片，当前选中的照片、已填的信息、正在预览的画面都保持不变。
- 删除照片不会从列表里自动消失（避免误操作时列表突然变化），需要重新打开目录。

## 沿用功能

- 导出中断后可以继续导出剩下的照片，跳过中断那张和上次失败的，不重复已完成。
- 照片移动或改名后自动认回，预设和信息跟着照片走；自动关联成功时底栏有提示。
- 底栏「重新关联」按钮只在有待关联照片时出现，用强调色；接不回可手动选照片，改名也能接。
- 关联面板点面板以外区域即关闭。
- 记住窗口位置和大小，下次打开回到原处；拔掉外接显示器会退回主屏。
- HEIC / HEIF 打开、预览、编辑、导出；广色域照片预览与导出颜色一致。
- 成片最长边 16384 像素、总像素约 1.34 亿；超出提示缩小尺寸。
- 没装 HEIC 解码时，提示下有两个按钮直接打开微软商店。
- 手机常见 HDR 用其中的普通画面；整张按高亮度编码的 HDR 暂不支持，会说明原因。

## 说明

- 这是制作版。改过的内置预设要点“保存预设”，才会写进制作版工作库。
- 内置预设已定稿，开发阶段不再修改，也不封包；第一个正式版完成后再统一封包。
- 不改原照片。
- 以后每次更新都会开一个新的小版本文件夹，不覆盖旧版本。
