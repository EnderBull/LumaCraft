# LumaCraft 0.15.1 · 照片搬动后自动接回记录（制作版）

2026-11-06，版本 0.15.1+44。沿用 0.15.0 的全部功能。开发过程继续使用制作版，第一个正式版完成后再封发行版。

## 本次新增

- 把照片从原来的文件夹挪到别处，软件仍能认出它，原来套用的样式、补填的信息都还在。
- 自动认出：文件名和拍摄时间都相同才算同一张，认不准的不猜。
- 认不出来的会提示，点底栏「重新关联 N 张」可以手动挑照片。改过名的照片也能手动接回，一次可以选多张。
- 一次选很多张时，软件先按拍摄时间把对得上的自动配好，列在下方等你确认；剩下的再逐对点选。配错一对可以点叉号退回重选。
- 导出时软件卡住或自己退出，下次打开会说明是哪一张，并请你把尺寸改小。

## 照片格式

- 文件夹里的 `.heic`、`.heif`、`.hif` 会和 JPG 一起出现。
- 缩略图、大图预览、编辑和导出都能打开。画面会转成普通屏幕用的颜色，导出仍是 JPG 或 PNG。
- 相机、镜头、时间这些拍摄信息会照常读出来。横竖方向由系统转正，不会再转一次。
- 预览只用够看清的尺寸，导出才用全尺寸。缩小后的预览和缩略图与大图颜色一致。
- 广色域照片（例如按 Display P3 保存的 JPG）预览和导出现在颜色一致。普通照片的处理方式和以前一样，速度不变。
- 成片最长边可以到 16384 像素，总像素约 1.34 亿。再大就提示缩小尺寸，不会生成半张图片。
- 手机里常见的 HDR 照片，用其中给普通屏幕准备的那张画面，不会做成更亮的成片。
- 整张按高亮度方式保存的 HDR，当前打不开，软件会直接说明。
- 照片文件损坏时，也会说明打不开。
- 如果这台电脑还不能读 HEIC，预览和导出失败时会说明原因，并给出两个按钮，点一下就打开微软商店里的“HEIF 图像扩展”和“HEVC 视频扩展”。你这台电脑已经装了，一般不用再装。
